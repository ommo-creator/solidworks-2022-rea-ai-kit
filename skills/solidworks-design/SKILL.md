# SolidWorks 设计（策略、参数化、审查）

用在**动手之前**：定交付物、收约束、选建模策略、把尺寸收进参数表、验设计意图、干净交接。
一旦要写代码、连 COM、跑脚本，切到 [`../solidworks-2022-automation/SKILL.md`](../solidworks-2022-automation/SKILL.md)。

17 章完整手册在 [`references/design-manual.md`](references/design-manual.md)（按需 `rg` 定位再读段，
不要整本读进上下文）。

---

## 六步流程

1. **澄清交付物** —— 零件 / 装配 / 工程图 / 模具 / 钣金 / 焊件 / 只做评审。
   交付物决定后面所有判据；没定下来就不要打开 SolidWorks。
2. **收约束** —— 尺寸、材料、工艺、公差、单位、标准（GB / ISO / 企业规范）、下游是出图还是仿真。
   缺的项标成 `待确认`，不要默认。
3. **选建模策略** —— 优先原生基准面 + 稳健草图轮廓；**不要在斜面/曲面上画草图**，
   那会让后续所有特征引用都变脆（手册第十六章给了这条的跨机验证过程）。
4. **参数化** —— 显式参数表或参数类；不要把一个尺寸散在十处字面量里。
   改一个尺寸要不要顺手改十个地方，是判断参数化好坏的唯一标准。
5. **验设计意图** —— 特征顺序、实体数、对称性、壁厚、圆角、倒角、孔数、配合引用。
   这一步是**在 CAD 里看**，不是看脚本有没有报错。
6. **干净交接** —— 尺寸台账 + 校验清单，然后才进自动化。

## 设计规则（每条都来自实际返工）

- 草图**尽量完全定义**；允许欠定义时，说清楚哪些自由度是故意的。
- 优先**正交基准面**与稳定引用，少靠"选某个面"；面一改号，整棵树就断。
- 族类零件用**设计表**或显式参数字典，不要复制十几个近似文件。
- 特征顺序固定成：**基础几何 → 次要特征 → 孔 → 圆角倒角 → 外观/属性**。
  圆角放最后，才有机会一次改完。
- 装配先把**重复实例数**数清楚，再决定用阵列、配合还是逐件插入。
- 出图前查：投影关系、注记顺序、孔标注、**公差链**。
- 模具/成形工具：先算工艺尺寸，**零件几何 ≠ 模具几何**。

## 与本仓库事实库的接口

设计阶段产出的东西，正好是自动化阶段的输入：

| 设计阶段产出 | 落到哪 |
|---|---|
| 参数表（尺寸字典） | 直接变成脚本里的参数类，见手册第十七章 |
| 尺寸台账 | 建模后的体积/质量**判据**要从这里算，见 [README 判据表](../../README.md) |
| 孔规格与定位清单 | 孔特征的输入；异型孔走 [`docs/08-hole-wizard.md`](../../docs/08-hole-wizard.md) |
| 装配接口定义 | 位姿与配合的输入，见 [`docs/19-assembly-scale.md`](../../docs/19-assembly-scale.md) |
| 出图要求（GB/T、孔表、BOM） | [`docs/06-line-art-figures.md`](../../docs/06-line-art-figures.md) |
