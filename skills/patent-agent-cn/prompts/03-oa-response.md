# 提示词 03 · 答复审查意见

用途：收到审查意见通知书（OA）后，逐条定策略、写修改方案、写意见陈述书。
**这一步比撰写更容易出错**：修改一旦超出原记载范围（专利法 33 条），后面全是白做。

使用前替换占位符：

| 占位符 | 替换成 |
|---|---|
| `<OA_PDF>` | 审查意见通知书（含正文与对比文件清单） |
| `<APPLICATION>` | 本申请的说明书 + 权利要求书（**原始提交文本**，不是修改稿） |
| `<D1>……` | 对比文件（有就列，没有就写"未提供"） |
| `<DEADLINE>` | 答复期限（用于提醒，不用于计算） |

---

```text
你现在担任中国专利代理师，处理一份审查意见通知书的答复。

【材料】只读：<OA_PDF>、<APPLICATION>、对比文件 <D1>。
不联网，不引入材料之外的技术特征。答复期限：<DEADLINE>。

【第一步：把通知书的每一条意见拆成可判定的命题】
按下面四类归档，每条注明通知书中的原话位置：
A. 形式缺陷（体例、标号、单位、引用关系）
B. 清楚/支持问题（权利要求不清楚、得不到说明书支持）
C. 新颖性（对比文件是否公开了某特征）
D. 创造性（区别特征 + 实际解决的技术问题 + 是否显而易见）

【第二步：逐条定策略，只能选这三种之一】
1. 争辩不修改：用于审查员的事实认定有误、或对比文件未公开该特征。必须引用
   对比文件原文位置 + 本申请对应段落，说明"哪一句没有公开什么"。
2. 修改 + 争辩：从说明书里把已记载的附加技术特征并入独立权利要求。修改依据必须写
   "原说明书第 X 段 / 图 N"，不得新增原文没有的表述。
3. 部分修改后保留争辩：缩小范围但保留核心技术点，用于确实存在区别、但原权项概括过宽。

禁止：为了绕开对比文件而引入原文没有的特征；禁止把说明书里的实施例效果写进权利要求当限定。

【第三步：输出】
1. 意见—策略对照表：通知书条目 / 归类(A/B/C/D) / 策略(1/2/3) / 一句话理由 / 修改依据位置
2. 修改后的权利要求书（全文重抄，改动处标注：新增下划线、删除删除线、修改处说明）
3. 修改对照表：原权项 / 新权项 / 改动类型 / 原文依据
4. 意见陈述书正文（按通知书条目顺序，每条一段：认可或反驳 → 事实依据 → 法律依据）
5. 风险提示：哪几条仍有被再驳的可能，为什么；哪些点建议补充实验数据或修改附图

【硬约束】
- 不许出现"申请人认为该对比文件与本申请技术领域不同因此不具备参考性"这种空泛抗辩，
  必须落到具体技术特征。
- 每一条"对比文件未公开"的判断，都要写清是"通篇未提及"还是"提及但未给出该结构/该连接关系"。
- 不清楚的地方写"需申请人确认"，不要替申请人编造技术事实。

不要客套。先给一句话结论：本次答复的总体方向是"争辩为主 / 修改为主 / 部分修改"。
```

---

## 答复阶段的四个死法

| 死法 | 长什么样 | 为什么致命 |
|---|---|---|
| 超范围修改 | 新增一个原文没有的连接关系 | 专利法 33 条，直接被驳 |
| 空泛抗辩 | "对比文件技术领域不同" | 审查员不采纳，只加一轮往返 |
| 只改不辩 | 把所有区别特征都并入独权 | 保护范围归零，授权了也没用 |
| 全盘争辩 | 一条都不改，逐条反驳 | 除非审查员认定确有错误，否则必再驳 |

**正确姿势是"最小修改 + 最强争辩"**：能被争辩解决的绝不修改，必须修改的
只并最少的特征，并保证并入的特征在原文里有明确记载。

## 与本仓库其他技能的接口

- 答复里要证明"对比文件没有这个结构"，往往需要几何/尺寸层面的论证：
  尺寸对不上的计算、装配关系讲不通的推演，可以用
  [`../../../docs/19-assembly-scale.md`](../../../docs/19-assembly-scale.md) §19.9 的口径
  （尺寸、间隙、装配高度）来算清楚，别用"显然不同"这类表述。
- 需要补附图时，附图合规要求见 [`01-blind-review.md`](01-blind-review.md) 第二部分，
  出图走 [`../../../docs/06-line-art-figures.md`](../../../docs/06-line-art-figures.md)。
- 答复前的自检用 [`../references/review-checklist.md`](../references/review-checklist.md)。
