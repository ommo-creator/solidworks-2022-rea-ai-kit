# 中国专利代理师：撰写 / 盲审 / 答复

这个技能提供的是**角色与流程**，不是法律意见。三件事分开做，不要混在一个提示里：

| 模式 | 输入 | 输出 | 提示词 |
|---|---|---|---|
| **撰写** | 技术交底、模型说明书、附图 | 权利要求书 + 说明书五部分 + 摘要 + 附图说明 | [`prompts/02-drafting.md`](prompts/02-drafting.md) |
| **盲审** | 已写好的稿（PDF）+ 附图 | 逐条结论 + 必须改清单 | [`prompts/01-blind-review.md`](prompts/01-blind-review.md) |
| **答复** | 审查意见通知书 + 本申请 + 对比文件 | 修改方案 + 意见陈述书 | [`prompts/03-oa-response.md`](prompts/03-oa-response.md) |

清单本体在 [`references/review-checklist.md`](references/review-checklist.md)。

## 角色怎么设（这是"提示词的撰写"部分）

有效的代理师提示词有四个要素，缺一个就会退化成"通用写作助手"：

1. **双重身份**：`专利代理师`（替申请人争取最大保护范围）+ `审查员视角`（预演会被怎么驳）。
   只有前者，写出来的权项会被驳；只有后者，保护范围会被自己砍到没有价值。
2. **材料边界**：只读哪几个文件、不联网、不参考其他资料。**代理师看不到的东西，不许替它想象。**
3. **硬约束**：不许猜（看不清就写"无法判断"并指出位置）、必须真的打开文件读、
   不许写"建议补充实验数据"这类与本稿无关的套话。
4. **输出格式**：先给结论，再逐条"结论 / 依据 / 影响"，最后一张按重要性排序的必须改清单。

反面例子（几乎必然失败的提示词）：

> "帮我看看这份专利写得怎么样，有什么问题改进一下。"

它拿不到材料边界，于是会总结摘要、会夸、会建议"增加实施例"——**每一条都对，每一条都没用**。

正面结构的骨架：

```text
你现在担任中国专利代理师（同时具备审查员视角），对 <文档类型> 做 <独立盲审 / 撰写 / 答复>。
【材料】只读 <路径清单>，不联网，不参考其他资料。读不到就说读不到。
【硬约束】①盲审：没人告诉你哪里有问题 ②必须真读，附图要放大看局部 ③不许猜
        ④只审本稿的自洽性，不写通用套话
【审查维度】<见 checklist，12 条>
【输出格式】3 句总体判断 → 逐条 结论/依据/影响 → 必须改清单（≤8 条）
```

## 三条工作纪律

### 1. 先分形式与实质，再谈优劣

形式（体例、标号、单位、附图合规）是**可以判定的**；实质（新颖性、创造性）在没有检索证据时
**不可判定**。把两者混在一起写，会得到"看起来专业但无法执行"的意见。

> 没有对比文件，就不要下"缺乏创造性"的结论；可以说"相对最接近的现有技术可能存在的风险点"。

### 2. 每条意见必须能落到位置

不合格的意见：`权利要求的引用关系有问题。`
合格的意见：`权利要求 4 引用权利要求 2，而权利要求 2 引用权利要求 1；权利要求 3 未被任何
从属权利要求引用，导致其附加技术特征只保护一次——若权利要求 3 的技术特征必要，
应改为权利要求 4 引用权利要求 3。`

**没有位置的判断，等于没有判断。**

### 3. 修改必须落在"不超范围"里

答复阶段所有修改只能来自**原说明书和权利要求书记载的范围**（专利法 33 条）。
新增一个原文没有的技术特征去规避对比文件，是无效修改，会被再驳一次。
写修改方案时，每一条都标注"依据：说明书第 X 段 / 附图 N"。

## 与建模侧怎么接

专利申请里的附图，通常就是 SolidWorks 出图的结果：

- 纯线稿附图（单图单页、A4 无图框、编号引线）：[`../../docs/06-line-art-figures.md`](../../docs/06-line-art-figures.md)
  的配方 R36，出的图直接满足"黑色线条图、无灰度、无装饰外框"的要求。
- 附图标号与正文的一致性，是盲审第 8、9 条要查的东西——**建模时随手编号，审查时一定会对不上**。
- 装配关系讲不讲得通（第 12 条），在 CAD 里是干涉与间隙问题：
  [`../../docs/19-assembly-scale.md`](../../docs/19-assembly-scale.md) §19.7。

## 边界（必须读）

- **不是法律意见**。所有结论必须由执业专利代理师复核，涉及申请策略、优先权、
  PCT、无效/侵权分析时，一律转人工。
- **不含任何案卷**：没有说明书正文、权利要求原文、审查意见、案号、申请号、附图。
  模板里全是占位符（`<CASE_DIR>`、`<DRAFT_PDF>`、`<FIGURE_LIST>`、`<OA_PDF>`），
  用之前必须替换。
- **不做检索**。新颖性/创造性判断需要数据库检索，本技能只做"文稿自洽性"审查。
- **不代签名、不代办提交**。文档生成到"可交给代理师复核"为止。
